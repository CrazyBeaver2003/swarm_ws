# Исправление магнитометра Gazebo для PX4 1.17

Патчи уже применены в `third_party/PX4-Autopilot`, SITL пересобран.
Они сохранены отдельно, потому что `third_party/` исключён из Git workspace.

Основа исправления: [PX4 PR #28877](https://github.com/PX4/PX4-Autopilot/pull/28877).
Перенесены настройки магнитометра, преобразование координат и единиц, а также
шум магнитометров. Прочие изменения новых версий PX4 и моделей не переносились.

Исходные ревизии:

- PX4 `v1.17.0`: `d6f12ad1c4f70ad3230afd7d86e971421e02fef4`.
- Подмодуль `Tools/simulation/gz`: `b6127f4ec20de867e215fb5f78ae88b80f371909`.
- Проверенная среда: Gazebo Harmonic 8.15.0; настройки требуют gz-sim >= 8.6.

## Изменения

- В `src/modules/simulation/gz_bridge/server.config` включены корректная мировая
  система координат поля и выдача в тесла: `use_earth_frame_ned=false`,
  `use_units_gauss=false`.
- В `GZBridge.cpp` поле преобразуется из FLU в FRD и из тесла в гауссы.
  Для внешних миров со старым форматом сохранена совместимость с явным
  предупреждением о неправильном курсе.
- В 13 моделях с явно заданным магнитометром шум согласован с новым режимом:
  `3e-7 T`, то есть `3 mG`. В эту группу входит `rc_cessna`.
- Порог `EKF2_ABL_LIM` и сохранённые параметры пользователя не менялись.

## Повторное применение после чистого клонирования

Команды предназначены для указанных исходных ревизий. В текущем checkout
патчи уже применены; повторять применение не нужно.

```bash
cd ~/swarm_ws/third_party/PX4-Autopilot
git apply --check ~/swarm_ws/patches/px4-v1.17.0-gazebo-magnetometer.patch
git apply ~/swarm_ws/patches/px4-v1.17.0-gazebo-magnetometer.patch

git -C Tools/simulation/gz apply --check \
  ~/swarm_ws/patches/px4-gazebo-models-magnetometer-noise.patch

  ~/swarm_ws/patches/px4-gazebo-models-magnetometer-noise.patch

GZ_DISTRO=harmonic make -j2 px4_sitl
```

## Выполненные проверки

- Сборка `GZ_DISTRO=harmonic make -j2 px4_sitl` успешна.
- Проверены стиль C++, whitespace diff, XML настроек и все 13 блоков шума.
- В отдельном мире Gazebo статичная Cessna проверена при шести ориентациях,
  включая крен и тангаж. Запускался только мост датчиков в отдельном экземпляре
  PX4; commander, армирование и полёт не запускались.
- Среднеквадратичное отклонение восстановленного мирового магнитного поля:
  `0.0032165 G`; величина поля остаётся в физически ожидаемом диапазоне.
- Проверочные процессы остановлены. Журналы и численные результаты находятся
  в `log/magnetometer_fix/`, включая `probe_results.json`.

## Проверка в полёте

Запустить стенд обычной командой:

```bash
source /opt/ros/jazzy/setup.bash
source ~/swarm_ws/install/setup.bash
ros2 launch swarm_bringup single_plane.launch.py
```

В QGroundControl выполнить взлёт и оставить самолёт в Hold на 15 минут.
Это перекрывает время появления предупреждения и дальнейшего расхождения
ориентации в исходном полёте. После завершения нужен анализ нового ULog:

- отсутствие `High Accelerometer Bias` после инициализации;
- отсутствие насыщения оценок смещения IMU на ограничениях EKF;
- отсутствие нарастающего расхождения ориентации с ground truth Gazebo;
- прохождение предполётных проверок при установленной связи с QGroundControl.

Контрольный ULog `2026-11-05/15_15_28.ulg` после исправления проверен:

- длительность записи — 7 минут 23 секунды, в воздухе — 7 минут 11 секунд;
- `High Accelerometer Bias` не возникало, предполётные проверки проходили
  с окончания инициализации до конца записи, failsafe не включался;
- смещение акселерометра Y к концу записи — `+0.0393 м/с²`, насыщения нет;
- на участке 30–420 секунд после взлёта медианная ошибка ориентации относительно
  Gazebo — `2.78°`, максимальная — `3.67°` (до исправления на таком же участке
  максимальная ошибка составляла `22.50°`);
- IMU работает на 250 Гц, ошибок датчиков, clipping и ULog dropouts нет;
- направление магнитного поля согласуется с ground truth: RMSE мирового поля
  `0.00378 G`, сопоставимо с заданным шумом магнитометра.

График сравнения и численные результаты сохранены в
`log/ulog_after_fix_2026-11-05/before_after.png`, `comparison.json`, `summary.json`.
Запись закончилась в воздухе; посадка в неё не вошла. Проверка полётом на полные
