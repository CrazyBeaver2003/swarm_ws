Полёт группы

После взлёта дождитесь высоты и Hold у всех самолётов. Затем включите строй. Выбор режима подтверждается телеметрией.

Формация

Команда лидеру

0° — север, 90° — восток. Курс, высота и скорость меняются плавно. При активной миссии сначала отмените её.

Автоматическая миссия

Миссия не запущена
Выбор цели доступен щелчком по карте. Высота и маршрут выбираются автоматически. Завершение — круг ожидания.

Замер метрик

Когда строй сформирован, начните замер. Завершите его через нужный интервал: отчёт будет рассчитан только по этому участку. Полный журнал полёта сохраняется отдельно.
Ожидание регистратора метрик
Маршрутные метрики появятся, если в интервал попал полёт по миссии. Для проверки взлёта, перестроений и всех сближений используйте отчёт всего полёта.
Ожидание статистики связи
Карта показывает mesh-оценку положения. Ground truth используется только отдельным модулем оценки.
